# Aozora剧情罗盘 v1.0.1

修复短剧情或资料稀少时，只有一条完整选项、空卡片等内容被当作成功结果展示的问题。

- 正确识别正文，不再把标题、路线名或事件摘要当作正文。
- 兼容 text/content 等正文标签，排除空白、不可见字符和占位内容。
- 五条常规路线不完整时显示“灵感未生成完整”，可直接点击重试。
- 保持一次手动生成或换批一次 API 调用，不自动追加请求。

这次修复加强解析与完整性校验，不代表能保证模型每次都写齐五条；模型未写齐时会明确提示。已通过 15 项解析检查和模拟 SDK 的稀疏资料/手动重试流程测试，真实模型表现仍需实际体验。

下载下方 `.tpg` 安装包，在 Tavo 中导入更新。需要 Tavo 1.3.0+ 和可用的文本 AI。

## English

Fixes incomplete or empty suggestions being displayed as a successful batch, especially in short scenes with limited character/world information. Metadata-only blocks and placeholders are rejected; common text/content body tags are supported. All five regular routes must be present, otherwise a clear retry state is shown. No automatic extra API call is made.

Verified with 15 parser/completeness checks and a mocked SDK flow covering sparse input, incomplete generation, and manual retry. This does not guarantee complete output from every live model response.

Import the `.tpg` asset to update. Requires Tavo 1.3.0+ and a configured text AI service.
