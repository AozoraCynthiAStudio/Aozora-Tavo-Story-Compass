# Aozora剧情罗盘 v1.0.1

优化选项解析与分组，减少选项不完整、标题或摘要被拆成选项等问题的出现频率。

- 按整条选项识别标题、路线、事件摘要和正文，改善多行返回内容的分组。
- 兼容 text/content 等正文标签，排除空白、不可见字符和占位内容。
- 五条常规路线不完整时显示“灵感未生成完整”，可直接点击重试。
- 保持一次手动生成或换批一次 API 调用，不自动追加请求。

这次更新是为了减少这些偶发现象，不保证完全消除。如果仍然出现内容不完整或选项异常，点击“重试”或“换一批”重新生成即可。

已通过 25 项解析检查和模拟流程测试，并经玩家试用。正式版本号仍为 v1.0.1，已更新本页安装包。

下载下方 `.tpg` 安装包，在 Tavo 中导入更新。需要 Tavo 1.3.0+ 和可用的文本 AI。

## English

Improves suggestion parsing and grouping to reduce incomplete options and cases where titles or summaries are split into separate cards. Supports multiline responses and common body tags, and shows a retry state when regular routes are incomplete. No automatic extra API call is made.

These occasional issues may still occur. If a result is incomplete or looks wrong, use Retry or Reroll to generate a new batch. Checked with 25 parser tests, mocked SDK flows, and player testing. This refreshed package retains version v1.0.1.

Import the `.tpg` asset to update. Requires Tavo 1.3.0+ and a configured text AI service.
