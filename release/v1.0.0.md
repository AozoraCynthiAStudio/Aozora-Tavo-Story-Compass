# Aozora剧情罗盘 v1.0.0

首个正式版。需要灵感时再点开，以独立面板提供交集、线索、抉择、开拓、亲密五条路线；符合剧情条件时可能追加特殊走向。选项可复制后修改，等待时可隐藏，完成后自动打开。

下载下方 .tpg 文件，在 Tavo 插件管理中导入。需要 Tavo 1.3.0+ 和可用的文本 AI。每次生成或换批额外调用一次 API；速度受模型和上下文影响，内容请核对后使用。

First public release. Generate five routes on demand in a dedicated panel, with an optional special path. Copy suggestions to the composer and edit them. Hide while generating; successful results reopen automatically while the scene remains current.

Import the .tpg asset in Tavo. Requires Tavo 1.3.0+ and a configured text AI service. Each generation or reroll makes an additional API call; latency varies and suggestions may need correction.
